# 毽球比赛抽签系统

## 一、系统简介

本系统是一个单文件网页抽签工具，文件位于：

```text
https://junji-luo.github.io/DrawSystem.HTML
```

无需安装，无需联网，使用浏览器直接打开即可使用。支持队伍随机分组、人员分档组队、Plus 分档抽签三种模式。

## 二、三种抽签模式

### 1. 普通队伍分组

- 适用场景：多个队伍直接随机分到若干小组。
- 使用方式：
  1. 在“队伍名单”中每行填写一个队伍名称。
  2. 设置“分组数量”。
  3. 点击“开始随机抽签”。
- 分组规则：
  - 队伍名单会先随机打乱。
  - 再按分组数量尽量平均分配。
  - 例如 11 支队伍分 4 组，数量为 3、3、3、2。

### 2. 普通分档

- 适用场景：A、B、C 三个档次的人员分别组队。
- 使用方式：
  1. 在 A、B、C 三个档次中分别填写人员名单，每行一个。
  2. 点击“开始随机抽签”。
- 分组规则：
  - 每个档次内部独立随机打乱。
  - 依次组合成若干组。
  - 例如 A 档 3 人、B 档 4 人、C 档 4 人时，会分成 4 组。
  - 人数不足的档次，在最后一组自动跳过。

### 3. Plus 分档

- 适用场景：分档更细，并需要尽量合理分配站位。
- 档次说明：
  - A 档
  - A- 档
  - B 档
  - B- 档
  - C 档
- 可选站位：
  - 不限制
  - 1 号位
  - 2 号位
  - 3 号位
- 使用方式：
  1. 在五个档次中填写人员名单。
  2. 可在每个姓名右侧选择站位号数。
  3. 点击“开始随机抽签”。
- 组合规则：
  - 优先按以下组合分组：
    - A 档 + B- 档 + C 档
    - A- 档 + B 档 + C 档
  - 两种组合随机排列。
  - C 档人员只会使用一次，不会重复分配。
  - 在满足组合规则的前提下，尽量让每组包含 1、2、3 号位。
  - 各档人数不均衡时，多出人员会补入有空位的小组或新增小组。

## 三、结果展示

- 分组结果显示在右侧“分组结果”区域。
- 每组标题显示“第 X 组”和该组人数。
- 普通分档和 Plus 分档会同时显示人员所属档次。
- 填写了站位的 Plus 分档人员，会在姓名后显示站位号数。

## 四、清空与刷新

- 点击“清空”会刷新页面，并恢复默认状态。
- 页面数据仅保存在浏览器本地，关闭浏览器后不会自动保留。

## 五、使用提示

- 姓名或队伍名称每行填写一个。
- 空白行会自动忽略。
- 如果抽签结果不符合预期，可再次点击“开始随机抽签”重新随机。
